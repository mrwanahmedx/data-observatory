# Public Data & Confidentiality Boundary

This is a public portfolio/research repository. Public work must remain completely separate from employment work.

## Allowed
- synthetic data generated for this repository,
- public datasets with compatible usage terms,
- public regulatory/academic methods with attribution,
- generic engineering patterns independently designed from public sources.

## Never publish
- employer or customer data,
- internal schemas, table/column names, queries, screenshots or reports,
- proprietary model coefficients, thresholds, parameters or monitoring outputs,
- internal workflows, approval logic, policies or undocumented procedures,
- credentials, account identifiers or private financial information,
- restricted/licensed data that cannot be redistributed.

## Clean-room rule
Renaming private variables is not enough. Public implementations must be independently designed from public standards/research or synthetic data and must not reproduce distinctive private-system logic.

When provenance is uncertain, do not publish.
