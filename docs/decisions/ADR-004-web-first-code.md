# ADR-004 — Make the portfolio web-first

**Status:** Accepted  
**Date:** 2026-09-26

## Context

Download-first portfolio buttons force recruiters to leave the site, inspect archives, or run code locally before understanding the work.

## Decision

Expose representative SQL, Python, saved outputs, methodology, and model diagnostics directly in the browser. GitHub remains the implementation reference.

## Consequences

- faster recruiter review,
- less dependency on local setup,
- browser code/result parity becomes testable,
- project downloads are no longer the primary portfolio interaction.
