# Engineering Decision Records

These records explain material design choices that affect analytical validity, reproducibility, or portfolio interpretation.

| ADR | Decision |
| --- | --- |
| [ADR-001](ADR-001-synthetic-data.md) | Use synthetic data for the Credit Lab |
| [ADR-002](ADR-002-logistic-baseline.md) | Keep a transparent logistic baseline |
| [ADR-003](ADR-003-grain-before-joins.md) | Define grain and aggregate before one-to-many joins |
| [ADR-004](ADR-004-web-first-code.md) | Make the portfolio web-first rather than download-first |
| [ADR-005](ADR-005-visible-regressions.md) | Preserve material failures and regression fixes in public history |

ADRs are intentionally short. They document the reasoning behind choices that a reviewer could otherwise misinterpret from code alone.
