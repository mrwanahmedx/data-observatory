# Data Observatory 3.2.0 — Model Development & Reliability

**Release date:** 2026-09-26

## Headline changes

### Synthetic Credit Risk Model Lab
A self-contained Python model-development project now lives under `risk-model-lab/`.

It demonstrates:

- raw one-to-many borrower/account/inquiry sources,
- explicit borrower-grain feature construction,
- train / validation / held-out test separation,
- transparent logistic baseline,
- validation-only calibration,
- validation-only threshold selection,
- held-out AUC / Gini / KS / Brier / calibration metrics,
- score PSI,
- PIT-style portfolio log-odds shifts,
- model-governance documentation and tests.

### Browser E2E coverage
Playwright coverage now checks:

- all primary public routes,
- browser/page errors,
- failed local requests,
- iScore dashboard initialization,
- SQL studio interaction,
- direct deep links,
- credit-risk SQL slider behavior,
- Suez year switching,
- mobile horizontal-overflow regressions.

### Decision records
The Risk Model Lab now records architectural decisions for:

- synthetic-data boundaries,
- grain-before-join controls,
- validation/test separation,
- transparent baseline-first modeling,
- fail-closed governance.

## Reliability position

This release continues the portfolio rule established after the iScore runtime regression: build success alone is not enough. Browser behavior, model-development controls, and documented evidence boundaries are part of the release gate.

## Known limitations

- Risk Model Lab data is synthetic.
- The split is borrower-disjoint but random, not out-of-time.
- The PIT mechanism is an educational log-odds shift, not regulatory calibration.
- No real lending, bureau, IFRS 9, capital, or pricing use is claimed.
