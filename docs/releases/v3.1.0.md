# Data Observatory v3.1.0 — Reliability & Engineering Evidence

**Release date:** 2026-09-26

This release turns reliability and analytical controls into visible portfolio evidence.

## Highlights

- Added Playwright browser E2E checks for major public routes.
- Added explicit checks that the Credit Risk Lab initializes and that its SQL studio exposes all 14 synthetic reports.
- Added browser interaction coverage across the interactive analytical pages.
- Added engineering decision records covering synthetic data, model baseline choice, grain control, web-first UX, and regression visibility.
- Preserved the public change trail for material bugs and reliability fixes.

A green source build is not enough. This release adds browser execution as a separate gate so runtime failures can block merge before deployment.
