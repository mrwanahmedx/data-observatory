# Data Observatory v3.2.0 — Clean-Room Risk Research

**Release date:** 2026-09-26

This release adds two tested, synthetic-only risk research modules and formalizes the repository's public-data boundary.

## Added

### IFRS 9 Credit Risk Modeling
- deterministic synthetic exposures,
- configurable Stage 1 / Stage 2 / Stage 3 logic,
- illustrative PD, LGD and EAD components,
- baseline / downside / upside scenarios,

### Credit Risk Model Validation

- fixed-bin calibration tables,
- PSI,
- observed-versus-expected binomial backtest,
- challenger comparison,
- explicit PASS / PASS WITH LIMITATIONS / REDEVELOPMENT REQUIRED logic,
- 4 passing core regression tests.

## Reference validation outcome

The deterministic weak-model demonstration produces **PASS WITH LIMITATIONS**.

Ranking is acceptable under the illustrative threshold, but calibration evidence is weak:
- calibration intercept: -1.4093,
- calibration slope: 0.4289,
- observed event rate: 10.42%,
- predicted event rate: 17.06%,
- observed-versus-expected backtest p-value: 9.68e-11.

The model is not presented as a clean pass merely because AUC is acceptable.
