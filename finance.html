01 / POWER BI / FINANCIAL ANALYSIS

A clearer view of
financial performance.

A finance dashboard project focused on banking KPIs, revenue versus earnings, and year-over-year performance.

01FIELD NOTES
Explore the demo ↓Project on GitHub ↗

THE QUESTION

How do revenue, earnings and balance-sheet indicators move together?

The original project explores multi-year financial performance in Power BI. The browser replica keeps annual KPIs, prior-year comparisons and ratios in one selected-year context so the analysis does not mix cumulative values with point-in-time metrics.

RECRUITER BRIEF

Financial analysis with one coherent time grain.

01

Problem

Present a dense multi-year bank dashboard without summing ratios or mixing annual comparisons with cumulative totals.

02

Data

Illustrative annual financial series covering 2002–2022 in the browser replica. It is not an official bank financial statement.

03

Method

Selected-year KPI views, revenue and earnings YoY analysis, balance-sheet indicators, profitability ratios and multi-year trends.

04

Engineering challenge

Keep every visual synchronized to one year state, calculate prior-year logic consistently, and constrain chart artwork inside Power BI-style visual containers.

05

Result

One year selection updates revenue, earnings, assets, cash, P/E, margin, ROA, ROE, debt/equity and highlights the corresponding table row. The trend and YoY charts retain the complete history for comparison.

06

Limitations

The web experience recreates the analytical interaction and visual logic; it is not a downloadable .pbix file or official Suez Canal Bank reporting.

07

Code

The browser dashboard and tested calculation core are versioned in Data Observatory, with the original Power BI project retained as the project reference.
