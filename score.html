How the model was built
  1. Features at the observation date
    Eight historical features; future outcomes are isolated. SQL aggregation preserves borrower grain.
  2. Separate borrower groups
    70/15/15 hash split within one synthetic cohort. Not out-of-time validation.
  3. Training the model
    Scaling and logistic weights fitted on training rows. Threshold selected on validation F1.
  4. Testing the model
    ROC, AP, Brier, KS, Gini and bootstrap AUC uncertainty. Subgroup exploration is descriptive.
Data checks and source
Fixed-model bootstrap intervals resample evaluation borrowers; they exclude retraining uncertainty. Coefficients and WOE are associations, not causal explanations.
